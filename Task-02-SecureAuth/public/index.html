🔍 Defensive Security Controls in Effect

🔐 Password Hashing

Bcrypt adaptive salt + work factor 10. Passwords are never stored or logged in plaintext.

🛡️ Server-Side Validation

Strict type checking, regex whitelist for usernames, and length boundary controls.

🍪 Hardened Sessions

Server-side session store with HttpOnly and SameSite=Lax cookie flags.

⏱️ Rate Limiting

Sliding window rate-limiter prevents automated brute-force attacks by issuing HTTP 429.

🚫 Generic Auth Errors

Returns identical "Invalid username or password." to block username enumeration.

🚪 Explicit Invalidation

Logout explicitly destroys the server-side session and wipes client cookie.
